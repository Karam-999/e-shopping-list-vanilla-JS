# Shopping List (Vanilla JS)

A simple JavaScript project to add and remove items from a list using DOM manipulation and event handling.

## Features

- Add items to a list via a form input
- Remove items from the list with a button
- Input validation to prevent empty entries
- Uses modern JavaScript (ES6+) and event listeners

## How to Use

1. Open `index.html` in your browser.
2. Enter an item in the input field and submit the form to add it to the list.
3. Click the remove button next to an item to delete it from the list.
